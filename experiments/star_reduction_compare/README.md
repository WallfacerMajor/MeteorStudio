# 星野缩星对比原型

## 工具箱入口

2026-09-22：本版本修改了 app.py 与 smoke.py，增加工具箱启动模式、返回入口、独立输出选择、路径传递和集成回归。engine.py 中的两种缩星算法未修改。修改后的对比程序继续按 GPL-3.0-or-later 分发。

星野工具箱首页 → 实验室 → 缩星。工具箱通过独立进程启动本程序；两种算法及同步对比均保留。
使用 `--toolbox` 启动时不加载示例照片，顶部返回按钮关闭本窗口并恢复工具箱。
打开照片后选择输出位置，程序创建独立时间戳目录。Siril 路径复用工具箱配置，缺少 Siril 或 StarNet 配置时打开设置。
组件源码与 GPL 许可证随软件保存在 `star_reduction/source`。

独立原型，不修改星野工具箱、用户项目或 Siril 的全局配置。
输入为已经显影、拉伸的照片；原始 RAW 和线性叠加文件不在本原型的输入范围内。

## 使用

运行 dist/StarReductionCompare/StarReductionCompare.exe。
默认载入 runs/galaxy-20260922 的全分辨率示例。
三个视图共享缩放和中心位置，滚轮缩放，拖动画面平移，1:1 查看像素。

右侧选择“同时计算”“仅本地方案”或“仅 Siril”，设置强度，点击播放图标执行。
首次通过 Siril 调用已安装的 StarNet 分离背景；以后同图复用无星背景。
“仅 Siril”是真实运行 Siril 命令行及 PixelMath，不是本地模拟。
Siril 图标可打开工作副本继续手动处理。日志按钮显示可复制日志。

每次打开新照片建立独立的时间戳输出目录。同一实验内重新运行更新相应结果文件。
原始照片不写入；原图、结果及无星背景尺寸完全相同，结果为 16 位 RGB TIFF，保留输入 ICC。
运行时使用私有 Siril 配置副本，模型与 Siril 均由本机已有安装提供。

## 两种方法

- 本地方案：从原图、无星背景分离滤色星点贡献，以星点最大 RGB 值计算统一中间调增益，降低外围贡献，保持提取层 RGB 比例。
- Siril：直接执行 DSA-Star_Reduction 的传递公式，每个颜色通道分别计算。
- 两者共用分离结果，但不是同一算法；相同界面百分比只代表相同参数映射，不保证主观缩星量相同。
- 强度 p∈[0,1] 对应 Siril 参数 0.5−0.45p。本地星点传递参数为 0.5+0.45p。

这是效果验证版，尚无地景保护蒙版。请同时检查地平线、银河密集区、边缘彗差和星色。
不把去星误识别或背景修补结果视为真实天体细节，不自动覆盖原图。

## 源码启动

python app.py [已有实验目录]

依赖：Python 3.11+、NumPy、Pillow、tifffile、imagecodecs；Tkinter。
