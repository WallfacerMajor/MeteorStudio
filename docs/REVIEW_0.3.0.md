# 星野工具箱 0.3.0 本地审查记录

本次工作基于含有大量既有修改的工作区进行；未重置既有改动，未推送 GitHub。程序继续输出到 `dist/MeteorStudio/MeteorStudio.exe`，显示名称改为星野工具箱。

## 产品与扩展结构

- `toolbox.py` 的 `WorkspaceSpec` 注册工作区入口，`ToolGroup` 与 `TOOL_MENU` 表示可递归扩展的分类树。首页分为“流星工具”和“控制点生成”，卡片子菜单、面包屑与工作区级联菜单共用这棵树。`SoftwareSpec`、`SoftwareRegistry` 注册软件名称、检测候选、PATH 名称与用户配置。新增集成可添加描述及工作区动作，不必更换根窗口或项目格式。
- Siril、PTGui、FFmpeg 使用共同路径解析。配置原子写入用户目录；显式路径失效时不静默选择其他版本。
- 控制点入口复用 `run_alignment_pipeline(export_layers=False)`，包括星点检测、匹配、独立镜头、PTGui 优化和完整素材工程生成，跳过图层渲染。对齐入口继续导出 16 位图层。
- `ui_theme.py` 统一夜空色板、中文无衬线字体、按钮状态、输入框、列表、标签页与进度条。图像像素本身不受主题影响。

| --- | --- |
| 产品导航 | 首页按“流星工具 / 控制点生成”分类，五个工作区位于对应子菜单；返回操作明确区分所属分类、上级和流星合成。跨分类菜单切换先执行旧工作区保存及关闭检查。 |
| 对齐布局 | 配置拆成两个标签页；结果操作分行；结果列表加入双向滚动；底部状态优先保留空间。 |
| 筛选布局 | 状态与标签筛选原先同时占据 row=1,column=1，现分列；候选操作分行；列表补充水平滚动。 |
| 线程与性能 | 扫描中的批量 EXIF 读取移入可取消后台任务；输入锁定；提交时捕获素材和确认轨迹快照。 |
| 数据一致性 | 路径改变后阻止使用旧扫描列表；空输入目录不当成当前目录。 |
| 输出安全 | 同名不同后缀素材在写入前明确拒绝，防止工程覆盖；对齐任务目录加入时间戳；默认输出根目录在素材目录旁。 |
| 状态准确性 | 控制点成功显示工程已生成；失败不冒充导出；没有图层时禁用回载；已导出的需复查图层不能被当成失败项覆盖。 |
| 数值校验 | 拒绝焦距及传感器参数中的 NaN、Inf 和非正数。 |
| 关闭可靠性 | 后台任务取消遍历使用快照，避免取消回调修改字典造成崩溃；关闭根窗口及筛选/视频页前清理自身 Tk 定时任务。 |
| 返回行为 | 筛选空导出路径不再变成当前工作目录；确认关闭后才回载；视频返回执行保存与取消流程。 |
| 内存 | 生成星点代理不再复制整张只读 RGB 帧，8K RGB 输入避免约 121 MiB 的额外瞬时副本。 |
| 错误诊断 | Siril 返回成功但没有生成星表时，在可复制错误中包含实际 CLI 输出。 |

## 验证边界

Windows 上的真实工具联调使用可复现的合成星空，不等同于所有真实镜头、RAW 格式和天气条件的准确性保证。现有检测、视频、模型及合成单元测试全部执行；没有重新训练模型，也没有遍历用户所有原片。macOS 路径、字体和构建入口继续保留，但此 Windows 环境不能执行 macOS APP/DMG 实机测试。

## 分类层级修正

按用户反馈，流星工具作为大类，其下为批量筛选、星空对齐、流星合成和视频动态；控制点生成作为另一大类，其下为 Siril + PTGui。主界面不再将五个工作流平铺为同级入口。分类卡片与工作区级联菜单共享可递归的分类树；支持面包屑、返回上级和返回所属分类。真实 Tk 点击覆盖首页分类、控制点子菜单、流星子菜单以及往返工作区。
