# 星野实验室

首页 → 实验室，独立于「流星工具」「控制点生成」，包含三个子菜单。

| 功能 | 输入与用途 | 输出 |
| --- | --- | --- |
| 星轨叠加 | 固定机位连续照片，逐像素取最大值 | 原尺寸 16 位 RGB TIFF |
| 已对齐降噪 | 已对齐、同尺寸及同曝光处理照片，逐像素平均 | 原尺寸 16 位 RGB TIFF |
| 批量画质体检 | 同机位同曝光序列，比较清晰度、背景亮度和过曝比例 | UTF-8 CSV |

支持 8/16 位 TIFF、PNG、JPG。当前不接受浮点、多页、透明 TIFF 或 RAW；请先转换。不会自动对齐、曝光归一化或剔除异常轨迹。取亮叠加会保留飞机与热像素；平均叠加也会削弱流星，不应用于保留流星的合成。

原片只读，输出必须位于素材目录之外。每次创建独立时间戳目录，包含 experiment.json，记录输入顺序、算法版本与完成/失败/取消状态。只有完成的 TIFF 命名为 result.tif。取消或关闭时等待当前不可中断的文件读写结束，之后停止。文件夹按钮打开结果。

素材列表按照片、格式、目录分列，支持多选后「移除选中」或 Delete，只修改任务列表。重复添加自动忽略，数量与最低要求显示在列表上方。运行期间输入锁定；取消结束后可以直接重跑，旧任务的迟到消息不会覆盖新任务。再次运行失败或取消仍可打开上次成功结果。软件路径配置集中在工具箱首页，子菜单通过「软件连接设置」返回。

画质体检的 sharpness 是最长边不超过 1600 像素的灰度拉普拉斯方差，不是星点 FWHM；景物、噪声、曝光也影响它。background 为分析图的灰度中位数，clipped_fraction 为原图任一通道 ≥ 65500 的像素比例。没有自动保留、删除或 AI 标签修改。

## 调研与开源使用记录（2026-09-20）

- [StarStaX 官方介绍](https://markus-enzweiler.de/software/starstax/)提供星轨、取亮及相关堆栈流程，启发本轮星轨功能选型。未复制其代码、图标或二进制；免费使用不等于开源授权。
- [Siril 官方图像分析](https://siril.org/tutorials/dynamic-psf/)介绍 FWHM 等星点质量度量；[手动处理](https://siril.org/tutorials/tuto-manual/)介绍叠加及异常值剔除。本轮只提供基础画质指标与平均叠加，未声称实现其 PSF、配准或拒绝算法。
- [GraXpert 官方仓库](https://github.com/Steffenhir/GraXpert)标明 GPL-3.0。渐变去除值得后续研究，但需处理银河、星云和地景保护及独立模型授权，本轮未集成或复制。

laboratory.py 和 laboratory_workspace.py 均为本项目新增实现，没有移植第三方源文件或模型，没有新增依赖；仅调用已有 NumPy、OpenCV、Pillow、tifffile 公共 API。上述链接是功能调研来源，不代表原项目代码已纳入。现有依赖仍适用各自许可证；本轮不改变项目或依赖的许可。今后移植代码必须同时记录上游版本、来源、完整许可和修改说明，再核对分发条件。

后续优先候选：带天空/地景保护的渐变去除、星点 FWHM 体检、带异常值剔除的对齐堆栈、星轨断缝填充。它们尚未实装，不在菜单提供占位入口。

## 本地验证

187 项单元测试通过，含叠加数值、16 位 PNG 通道保真、输入哈希不变、取消状态及真实 Tk 操作。源码和 Windows 打包版均通过 16 项工具箱及实验室交互检查（含移除选中、运行中锁定、取消重跑、旧消息隔离、失败保留上次结果）与 61 项合成交互回归。已检查实验室截图。macOS 构建路径保持不变，本轮没有运行 macOS 实机测试；实验图像为合成测试素材，不代表完成大规模真实素材质量评估。
