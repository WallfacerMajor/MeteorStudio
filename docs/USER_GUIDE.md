# MeteorStudio 使用指南

## 1. 软件用途

MeteorStudio 包含三个连续环节：

1. 使用 Siril 辅助寻找星点，由 PTGui 将每张流星原图对齐到干净底图。
2. 自动提出流星候选，用户通过分数阈值、画笔和橡皮擦确认最终蒙版。
3. 将流星自然融合到底图，并按需调整位置、旋转、长度、宽度、亮度和局部曝光。

输入素材始终只读。缓存、PTGui 工程、对齐层、蒙版和最终成品全部写入独立输出目录。

顶部按钮采用单工作区导航：进入“视频动态”或“Siril＋PTGui 对齐”时，图片合成界面自动隐藏；点击“返回图片合成工作区”或关闭当前工作区即可返回，不会同时显示两个完整工作区。

## 2. 准备软件

- Windows 10/11 或 macOS 12 及以上版本。
- PTGui 12 或更新版本。
- Siril 1.2 或更新版本，推荐 1.4。
- 视频工作区需要 FFmpeg；发布版若已内置 FFmpeg 则无需另行安装。

PTGui 和 Siril 是独立软件，不随 MeteorStudio 分发。第一次使用星空对齐工作区时，应在界面中确认两者的可执行文件路径。

## 3. 推荐输入结构

- 首先选择最终输出方式：
  - `拼合到同一张底图`：只能选择一张已经去除飞机线和流星的 TIFF/JPG/PNG，全部流星累计到这张底图并输出一张总图。
  - `分别输出`：可选择一张或多张底图，也可选择底图文件夹；软件按照主文件名与流星 TIFF 逐张配对并分别输出。
- `流星原图文件夹`：每张包含至少一颗流星的完整 TIFF，不要提前抠图。
- `独立输出文件夹`：必须与上述素材文件夹分开。

原图和底图应来自同一机位、同一镜头与相同画幅。底图可以经过不同曝光和色彩处理。

## 4. 星空对齐

1. 启动 MeteorStudio，点击右上角“`Siril＋PTGui星空对齐…`”。
2. 选择干净底图、流星原图文件夹和独立输出文件夹。
   后续重新选择底图时，软件会自动更新配对并使旧预览失效，无需再次手动扫描素材。
3. 确认 PTGui、Siril 路径。焦距和传感器对角线输入仅在某张图片EXIF缺失时作为兜底；正常情况下软件逐张读取实际焦距。
4. 星空区域由软件逐张自动判断。Siril星点会生成稀疏的“星点有效区”蒙版，只保留可信星点附近区域；地景、灯光和孤立亮点不会进入PTGui控制点。
5. 开始处理。

程序会为底图和每张流星照片建立独立镜头组，并按各自EXIF焦距创建独立 PTGui 工程；同一批素材可以包含不同焦段。一个工程失败不会影响其他工程。结果列表显示每张图片的焦距来源、星点有效区覆盖率、控制点数量和误差。覆盖率表示实际参与匹配的星点邻域，并不是整片天空占画面的比例。

结果状态：

- `已导出`：自动对齐通过检查。
- `已导出（需复查）`：已经得到基础对齐，但建议在 100% 视图检查星点。
- `已输出（原始状态）`：无法建立可靠变换，仍保留原图供手动放置。

回到主工作区后，可选择图片并点击“`切换查看/绘制源：自动对齐 / 原始图`”。这个按钮只决定当前看哪张图，以及接下来新画的蒙版从哪张图提取像素，不再把整张照片中的所有流星一起切换。已经建立的流星会各自保存“自动对齐素材”或“原始素材”。

## 5. 选择流星

主界面按工作范围分成 `3 蒙版与候选`、`4 融合与底图`、`5 所选流星` 三个页签，原有功能均保留。进入原图视图会自动显示蒙版工具；进入干净底图或融合视图会显示融合设置；在融合/来源标注中单击一颗流星后会自动显示单颗设置。素材扫描或项目恢复成功后，“1 素材与输出”会自动收起以扩大画布，随时可用窗口顶部按钮重新展开。

1. 点击“自动检测全部”得到初始蒙版。
2. 双击图片，在原图、干净底图、最终融合和来源标注之间切换。来源标注视图与最终融合使用同一合成结果，只额外显示来源框线和文件名。
3. 日常编辑使用最长边 1800px 的快速预览。需要判断暗部边缘、羽化和最终亮度时，点击“生成并打开导出级精确预览”；软件会按原始尺寸和 16 位导出链路计算，并自动以 100% 原始像素打开独立检查窗口。画面大于窗口时只显示局部，可用滚轮缩放、左键拖动平移，“适合窗口”查看全图；也可在最终效果和来源标注之间切换。关闭窗口后可用“打开已生成预览”再次查看。蒙版或参数变化后必须重新生成，避免继续查看过期结果。
   主编辑画布本身也支持滚轮缩放、中键拖动、空格加左键拖动和 100% 查看；主画布缩放使用快速预览像素，正式质量仍以导出级精确预览为准。
3. 按住 `H` 临时隐藏红色蒙版，检查是否完整覆盖流星亮部、光晕和尾迹。
4. 漏检时点击“AI分析当前单张候选”，降低分数阈值，或直接点击候选旁的绿色“＋选中”。
5. 使用画笔补充、橡皮擦修整。确认的蒙版可右键锁定。
6. 若流星周围出现淡色块，提高该颗流星的“周边净化”。软件会自动执行类似 PS“变亮＋色阶压黑场＋软边清理”的亮度门控，只保留高于局部天空噪声的流星信号。

画笔和橡皮擦采用按时间顺序的图层语义：先画后擦会移除区域，擦除后再画则会把蒙版补回来。连续绘制多笔不会替换前一笔。

常用操作：

- `B` / `E`：画笔 / 橡皮擦。
- 按住 `Alt`，macOS 按住 `Option`：临时切换画笔与橡皮擦。
- `[` / `]`：调整当前工具宽度。
- 单击起点后 `Shift+单击`：绘制直线或连续折线。
- 蒙版附近右键：锁定、删除或变换整颗流星。
- `Ctrl/Command+Z`：撤销。
- `3` / `4`：在无标记最终融合与来源标注预览之间切换。两个视图不绘制新蒙版，但都能直接编辑已经选中的流星对象。
- `2 干净 JPG`：纯底图只读检查，不显示红色蒙版、候选或画笔，也不能在该视图误画；蒙版编辑统一在 `1 原图 TIFF` 完成。
- 画笔与常规绘图软件一致：按下并拖动连续加笔，前台红色笔迹跟随鼠标，松开后一次性并入现有蒙版；按住 Shift 可从上一笔终点直连到当前点。之后继续单击或拖动只会追加，之前的线段始终保留；`Esc` 只取消正在绘制的一笔。
- 绘制期间鼠标由画布捕获，松开即使发生在画布外也会提交；若系统漏发松开事件，下一次按下会先提交上一笔再开始新笔，避免第二笔覆盖第一笔。
- 相邻、重叠或交叉的画笔始终做并集，后一笔不会减少前一笔。软件同时防止 Alt/Option 临时橡皮擦因系统漏发按键松开而错误延续到下一笔，并保持候选阈值变化前后的画笔/橡皮擦历史顺序。
- 单击流星显示变换框；拖动内部可移动，端点调整长度，侧边调整宽度，四角等比例缩放，圆形手柄旋转。`Delete/Backspace` 删除；方向键微移，`Shift+方向键` 移动 10 px；右键可删除、重置或输入精确参数。
- 拖动期间会实时移动流星像素本身，蒙版和变换框同步跟随；松开鼠标后软件再生成精确总融合，因此不会出现“只移动蒙版、流星留在原处”的假预览。
- 拼合模式的小范围修改采用增量预览：只替换当前流星层并保留其余画面缓存；连续滑块操作会合并，停下后后台只做一次精确校验。画布不会先清空再整张重建，导出质量与计算方式不变。
- 几何变换后的流星会标记为“已人工变换”。切回 `1 原图 TIFF` 时，原位置和原始流星仍然保留，同时叠加显示变换后的副本；青色虚线是原位置，橙色实线是变换后位置。
- 修改一颗流星后，无标记最终效果与来源标注会同步重新生成。拼合模式可在总图中选择任意来源的流星；分别输出模式只编辑当前图片对。
- “锁定”只保护蒙版不被候选阈值、重新检测和批量清除移除；在最终画布中执行的主动变换或删除不受限制。

## 6. 融合和变换

在流星蒙版附近右键，选择“进入预览直接移动／旋转／拉伸”，软件会切到当前图融合预览并显示与总融合预览完全相同的变换框。拖动流星主体即可移动，拖动边框手柄可直接调整：

- 水平和垂直位置；
- 旋转角度；
- 沿流星方向的长度；
- 横向宽度；
- 不透明度。

精确参数窗口不再是单张流星变换的必经步骤，只保留在融合预览右键菜单中作为可选的数值输入。工具栏的“↶ 一键恢复原位”和右键菜单都可以恢复该颗流星。恢复只清除位移、旋转和长宽缩放，蒙版、不透明度、亮度、羽化及其他融合参数保持不变。在“5 所选流星”或右键菜单中，可单独为当前流星选择“自动对齐素材”或“原始素材”，同一张照片中的其他流星不受影响。

“全局默认：保持流星亮部”默认开启，会补偿蒙版羽化、曝光匹配及变换插值造成的亮度损失。“全局亮度”默认 `100%`，只改变流星高于底图的正向信号，不会整体抬高天空；范围为 `50%–250%`。勾选“当前图单独设置”后可覆盖全局亮度，取消勾选即重新跟随全局。

“全局背景净化”默认 `70`，会读取蒙版羽化区域中的天空差异，移除原图图层相对底图的平滑亮度和 RGB 色偏。它专门用于减轻流星周围颜色不同、矩形补丁或光圈边缘；若附近有强烈地景边缘，可降低该值。

“底图曝光”范围为 `-2.0 EV–+2.0 EV`。它只改变干净底图，已经提取出的流星信号保持原亮度，因此可以先调整整体星空明暗，再用全局或单颗流星亮度控制流星。该设置会进入项目，并同时作用于预览、来源标注、JPG 和 16 位 TIFF 导出。

默认背景净化对暗部使用更强的黑场抑制：低于流星有效信号阈值的微弱亮度和色偏会进一步衰减，而连续的流星核心与尾迹仍由信号支撑范围保护。

长期建议启用“自动优化每颗流星”，默认档位使用“标准”：

- `自动优化当前流星`：先在最终融合或来源标注中选中一颗流星，再按原始分辨率分析。
- `自动优化全部流星`：逐颗分析所有有效正向蒙版；耗时接近一次完整导出，但每颗流星会得到不同参数。
- `保守`：优先保留极弱尾迹，背景抑制较轻。
- `标准`：根据局部信噪比平衡尾迹与暗部边界，建议默认使用。
- `强力`：适合明亮流星或明显色块，使用更大的有效羽化和更高黑场。
- `恢复自动值`：清除该颗流星亮度和净化的手动覆盖，重新使用已分析的自动值。
- `恢复原始融合`：关闭该颗流星的自动黑场与自动羽化；分析结果仍保留，之后可一键恢复自动值。

自动分析不会改写画笔点、画笔宽度或用户填写的羽化。它保存独立的“有效羽化”用于合成，并通过连续、细长的亮光组件保护流星核心与尾迹，降低普通星点和块状残差的权重。

合成时软件还会在每条蒙版中锁定占主导的连续流星亮光，只把该信号叠加到底图。宽蒙版里碰巧包含的普通星点、天空纹理、地景或投影接缝不会随原图图层一起进入成品。

局部曝光匹配、暗部压低、亮部提升和流星曲线仍按单张图片保存。建议先保持 `100%` 检查真实亮度，需要强调时再提高到约 `110%–130%`。

同一张图中多颗流星融合效果不同时，切换到 `3 最终融合` 或 `4 来源标注`，单击目标流星，再勾选“单颗独立设置”。可分别设置这颗流星的亮度、背景净化、饱和度、亮部保持、局部曝光/颜色匹配、混合方式和羽化。取消勾选会清除该颗流星的覆盖值，使其重新跟随当前图片和全局设置；这些参数会自动保存到项目。

## 7. 保存与导出

- 软件约在修改后 0.8 秒自动保存。
- “保存项目”可生成具名 JSON 项目文件。
- 点击“导出合成结果”后，结果进入新的时间戳目录，不覆盖旧结果。
- 拼合模式在内存中累计全部已选流星，最后只写入一张总合成图；分别输出模式以原图主文件名生成独立文件，彼此不会覆盖。
- 拼合模式会同时生成一张文件名带“`来源标注`”的诊断 JPG；分别输出模式也会为每张成品生成对应标注图。它用框线、引线和 TIFF 主文件名标明每颗流星的来源，方便定位融合效果不理想的原图；正常成品保持无标记。
- 若某颗流星使用“原始素材”，来源标注会改用红色警示框、黄色外框、顶部警告条和 `ORIGINAL / UNALIGNED` 标签，提醒重点检查位置；正常最终图不会出现这些标记。同一张照片可以同时包含自动对齐流星与原始素材流星。
- 若流星经过人工移动、旋转或拉伸，来源标注会使用橙色框和 `TRANSFORMED` 标签，并用青色虚线框及箭头标出原位置；导出的处理报告会记录具体变换参数。
- 默认生成 JPG、蒙版和处理报告；可选 16 位 TIFF。
- 导出完成时可选择是否用最终人工蒙版继续训练本地候选模型。

## 8. 输出目录

一次对齐任务通常包含：

- `cache/`：只读代理图、逐张自动星点有效区蒙版和 Siril 星表。
- `ptgui_project/ready_projects/`：每张照片独立的 PTGui 工程。
- `aligned_layers/`：对齐后的 16 位流星图层。
- `aligned_reference/`：对齐画布中的干净底图。
- `alignment_manifest.json`：状态、误差和文件对应关系。
- `final_composite/`：最终合成输出。

可以删除不再需要的任务输出，但不要删除仍在项目中使用的对齐图层。

## 9. 常见问题

### PTGui 工程中为什么没有流星蒙版？

PTGui 只负责星空投影和对齐。流星选择与蒙版在 MeteorStudio 中完成，避免让 PTGui 的控制点或蒙版误判飞机线。

### 为什么某张显示“需复查”？

通常是天空背景过亮、薄云、飞机线过多、星点较少或底图处理差异较大。软件仍会保留基础对齐；如果不满意，可切换回原始状态。

### 会修改原始 TIFF 吗？

不会。程序只读取输入文件，所有新文件都写入独立输出目录。
