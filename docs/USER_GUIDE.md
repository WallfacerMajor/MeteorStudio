# MeteorStudio 使用指南

## 1. 软件用途

MeteorStudio 包含三个连续环节：

1. 使用 Siril 辅助寻找星点，由 PTGui 将每张流星原图对齐到干净底图。
2. 自动提出流星候选，用户通过分数阈值、画笔和橡皮擦确认最终蒙版。
3. 将流星自然融合到底图，并按需调整位置、旋转、长度、宽度、亮度和局部曝光。

输入素材始终只读。缓存、PTGui 工程、对齐层、蒙版和最终成品全部写入独立输出目录。

## 2. 准备软件

- Windows 10/11 或 macOS 12 及以上版本。
- PTGui 12 或更新版本。
- Siril 1.2 或更新版本，推荐 1.4。
- 视频工作区需要 FFmpeg；发布版若已内置 FFmpeg 则无需另行安装。

PTGui 和 Siril 是独立软件，不随 MeteorStudio 分发。第一次使用星空对齐工作区时，应在界面中确认两者的可执行文件路径。

## 3. 推荐输入结构

- 首先选择最终输出方式：
  - `拼合到同一张底图`：只能选择一张已经去除飞机线和流星的 TIFF/JPG/PNG，全部流星累计到这张底图并输出一张总图。
  - `分别输出`：可选择一张或多张底图，也可选择底图文件夹；软件按照主文件名与流星 TIFF 逐张配对并分别输出。
- `流星原图文件夹`：每张包含至少一颗流星的完整 TIFF，不要提前抠图。
- `独立输出文件夹`：必须与上述素材文件夹分开。

原图和底图应来自同一机位、同一镜头与相同画幅。底图可以经过不同曝光和色彩处理。

## 4. 星空对齐

1. 启动 MeteorStudio，点击右上角“`Siril＋PTGui星空对齐…`”。
2. 选择干净底图、流星原图文件夹和独立输出文件夹。
3. 确认 PTGui、Siril 路径、镜头焦距和传感器对角线。全画幅默认 `43.2666 mm`。
4. 调整“顶部作为星空区域”。它应覆盖星空，但尽量不要包含地景。
5. 开始处理。

程序会从时间轴均匀抽取最多 5 张照片自动标定镜头畸变，然后为每张流星照片创建独立 PTGui 工程。一个工程失败不会影响其他工程。

结果状态：

- `已导出`：自动对齐通过检查。
- `已导出（需复查）`：已经得到基础对齐，但建议在 100% 视图检查星点。
- `已输出（原始状态）`：无法建立可靠变换，仍保留原图供手动放置。

回到主工作区后，可选择图片并点击“`切换：自动对齐 / 原始状态`”。如果基础对齐不理想，可恢复到原始状态再手动移动、旋转和拉伸流星；此切换不会删除蒙版。

## 5. 选择流星

1. 点击“自动检测全部”得到初始蒙版。
2. 双击图片，在原图、干净底图、最终融合和来源标注之间切换。来源标注视图与最终融合使用同一合成结果，只额外显示来源框线和文件名。
3. 按住 `H` 临时隐藏红色蒙版，检查是否完整覆盖流星亮部、光晕和尾迹。
4. 漏检时点击“AI分析当前单张候选”，降低分数阈值，或直接点击候选旁的绿色“＋选中”。
5. 使用画笔补充、橡皮擦修整。确认的蒙版可右键锁定。

常用操作：

- `B` / `E`：画笔 / 橡皮擦。
- 按住 `Alt`，macOS 按住 `Option`：临时切换画笔与橡皮擦。
- `[` / `]`：调整当前工具宽度。
- 单击起点后 `Shift+单击`：绘制直线或连续折线。
- 蒙版附近右键：锁定、删除或变换整颗流星。
- `Ctrl/Command+Z`：撤销。
- `3` / `4`：在无标记最终融合与来源标注预览之间切换；两个预览视图均不可绘制蒙版。

## 6. 融合和变换

在流星蒙版附近右键，选择“移动／旋转／拉伸这颗流星…”，可分别调整：

- 水平和垂直位置；
- 旋转角度；
- 沿流星方向的长度；
- 横向宽度；
- 不透明度。

“恢复真实位置”只清除该颗流星的创意变换。“切换：自动对齐 / 原始状态”则切换整张素材所使用的底层图像。

局部曝光匹配、暗部压低、亮部提升和流星曲线均按单张图片保存。建议先匹配周围天空，再适度提高流星亮部。

## 7. 保存与导出

- 软件约在修改后 0.8 秒自动保存。
- “保存项目”可生成具名 JSON 项目文件。
- 点击“导出合成结果”后，结果进入新的时间戳目录，不覆盖旧结果。
- 拼合模式在内存中累计全部已选流星，最后只写入一张总合成图；分别输出模式以原图主文件名生成独立文件，彼此不会覆盖。
- 拼合模式还会同时生成一张文件名带“`来源标注`”的诊断 JPG。它用框线、引线和 TIFF 主文件名标明每颗流星的来源，方便定位融合效果不理想的原图；正常总合成图保持无标记。
- 默认生成 JPG、蒙版和处理报告；可选 16 位 TIFF。
- 导出完成时可选择是否用最终人工蒙版继续训练本地候选模型。

## 8. 输出目录

一次对齐任务通常包含：

- `cache/`：只读代理图和 Siril 星表。
- `ptgui_project/ready_projects/`：每张照片独立的 PTGui 工程。
- `aligned_layers/`：对齐后的 16 位流星图层。
- `aligned_reference/`：对齐画布中的干净底图。
- `alignment_manifest.json`：状态、误差和文件对应关系。
- `final_composite/`：最终合成输出。

可以删除不再需要的任务输出，但不要删除仍在项目中使用的对齐图层。

## 9. 常见问题

### PTGui 工程中为什么没有流星蒙版？

PTGui 只负责星空投影和对齐。流星选择与蒙版在 MeteorStudio 中完成，避免让 PTGui 的控制点或蒙版误判飞机线。

### 为什么某张显示“需复查”？

通常是天空背景过亮、薄云、飞机线过多、星点较少或底图处理差异较大。软件仍会保留基础对齐；如果不满意，可切换回原始状态。

### 会修改原始 TIFF 吗？

不会。程序只读取输入文件，所有新文件都写入独立输出目录。
