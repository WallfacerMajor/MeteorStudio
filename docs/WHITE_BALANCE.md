# 白平衡

入口：星野工具箱 → 色彩工具 → 白平衡。天空合成未开发。

1. 打开照片。支持 8/16 位 RGB／灰度 TIFF、PNG、JPG，以及 rawpy 可解码的 ARW、NEF/NRW、CR2/CR3/CRW、DNG 等 RAW。
2. 调整色温偏移（冷／暖）与色调（绿／洋红）。零值保留当前解码结果。这里是相对色彩调整，不能反推出 JPEG/TIFF 的拍摄色温，也不是绝对开尔文设置。
3. 可以启用「取中性点」，点击本来应为灰色或白色的区域。使用原始像素周围 15×15 区域的有效像素估计增益，排除过暗、过曝像素；新取样会清零手动偏移。不要把彩色星点、星云或光污染当作灰卡。
4. 使用适合窗口、1:1、滚轮缩放和拖动平移检查效果。「查看原图」只控制对比显示，不改变导出参数。
5. 选择原片目录之外的输出位置，导出独立时间戳文件夹：result.tif（完整分辨率 16 位 sRGB）和 white_balance.json（来源、参数、状态）。设置也可单独保存、载入，或从导出的 JSON 恢复。

## 处理与限制

- 使用线性 sRGB 的逐通道增益，之后编码回 sRGB；查找表保证零调整的所有 16 位输入值精确不变。显式嵌入其他 ICC 色彩空间的图片要求先转换至 sRGB；无 ICC 的图像按 sRGB 处理。当前不支持浮点／线性 TIFF、CMYK、透明通道图像。
- RAW 先使用相机白平衡、关闭自动提亮、解码至 16 位线性 sRGB，再编码进入上述处理流程。后续调整是解码后的 RGB 校正，不是 RAW 传感器级白平衡；已经裁切的高光无法恢复。
- 过强的增益可能裁切通道，预览下方显示可见区域的通道触顶比例；它不是全图过曝统计。星点原有颜色不会被自动识别为偏色并逐颗中和。
- 原始像素只读。预览采用多分辨率缓存和可替换后台任务，只处理可见区域；缩小视图存在重采样差异，1:1 用于检查原始细节。调节参数或切换对比不重置视口。
- 导出重新读取原片，按 128 行分块处理，内存映射写入 16 位 TIFF，嵌入 sRGB ICC。取消时保留标记为 cancelled 的记录，未完成文件不会命名为 result.tif。
- 解码、导出在后台执行。关闭工作区发出取消，文件解码／写入等不可中断阶段完成后停止。

## 来源与许可

计算及工作区代码为本项目自行实现，没有复制第三方代码或引入新依赖。sRGB 转换公式参考 [ICC sRGB 规格](https://registry.color.org/rgb-registry/files/sRGB.pdf)，RAW 调用参数依据 [rawpy 官方 API](https://letmaik.github.io/rawpy/api/rawpy.Params.html)。现有依赖继续适用各自许可证。

测试使用合成 16 位素材验证像素、取样、视口和实际导出；没有真实相机 RAW 样本时，不把 RAW 格式支持列表视为逐机型验证承诺。macOS 本轮未作实机验证。

验证范围：193 项单元测试；工具箱交互覆盖滑块、原图对比、中性点取样、设置保存／恢复、原片哈希及 16 位导出，另包含最小窗口设置可达性。原有 61 项合成交互回归继续执行。正常缩放和小窗口截图均作人工检查。
