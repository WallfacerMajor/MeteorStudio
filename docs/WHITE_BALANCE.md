# 白平衡

入口：星野工具箱 → 色彩工具 → 白平衡。天空合成未开发。

1. 打开照片。支持 8/16 位 RGB／灰度 TIFF、PNG、JPG，以及 rawpy 可解码的 ARW、NEF/NRW、CR2/CR3/CRW、DNG 等 RAW。
2. 调整色温偏移（冷／暖）与色调（绿／洋红）。零值保留当前解码结果。这里是相对色彩调整，不能反推出 JPEG/TIFF 的拍摄色温，也不是绝对开尔文设置。
3. 可以启用「取中性点」，点击本来应为灰色或白色的区域。使用原始像素周围 15×15 区域的有效像素估计增益，排除过暗、过曝像素；新取样会清零手动偏移。不要把彩色星点、星云或光污染当作灰卡。
4. 使用适合窗口、1:1、滚轮缩放和拖动平移检查效果。「查看原图」只控制对比显示，不改变导出参数。
5. 选择原片目录之外的输出位置，导出独立时间戳文件夹：result.tif（完整分辨率 16 位 sRGB）和 white_balance.json（来源、参数、状态）。设置也可单独保存、载入，或从导出的 JSON 恢复。

## 改机天文素材

入口名称为「色彩工具 → 白平衡与改机校准」。调整、输出目录和导出操作统一位于画布右侧，可滚动查看「改机与滤镜校准」；底部仅显示状态与进度。

- **记录设备组合**：机身、Hα 增强／全光谱等改机方式、滤镜和参考光源随设置保存。名称只是标记，不会触发固定的减红系数。不同光学组合应分别保存 JSON 预设。
- **选择 RAW 基准**：相机白平衡沿用各照片的相机设置；固定日光关闭相机及自动白平衡，使用解码器的日光基准，适合同一机身整组处理。基准不是天文测光校色。更改基准会清除旧取样和手动偏移，应在新基准下重新校准；载入预设时会按预设基准重新解码当前 RAW。
- **灰卡参考流程**：先在同一机身、滤镜及所选解码基准下打开参考照片，在灰卡中部取样，填写参考光源和拍摄条件，再保存预设。加载该预设会启用「下一张沿用当前校准」。勾选后打开星野素材，保留增益、强度、手动偏移与设备记录；取消勾选后，新照片清零图像调整。
- **校准强度**：0% 不应用取样增益，100% 完整应用，冷暖／色调仍可独立微调。它是校正混合强度，不是 Hα 蒙版，也不自动识别星云。没有全图灰度平均、逐张自动中和红色或自动背景中和。
- **整组应用**：选好独立输出目录，点击「批量应用当前设置」，选择照片。快照一套参数逐张导出，不逐张估算白平衡；内存不会随张数累加。生成改机批量时间戳目录，各照片位于「序号_原文件名」子目录，保留 16 位 TIFF 和设置记录，batch.json 汇总来源、成功／失败与取消状态。重复路径只处理一次；坏文件会记录错误后继续；取消保留已完成结果及未完成记录。

固定参数只能保证处理方式一致：不同曝光、光污染或滤镜下的素材仍可能呈现不同颜色。当前是解码后的 sRGB 增益校正，不是针对改机光谱响应建立的相机色彩矩阵，也不能恢复已混入红外的真实可见光颜色。灰卡参考不能替代星表测光校色。大范围星云不应被当作中性参考区。

处理原则参考 [Siril 手动色彩校准](https://siril.readthedocs.io/en/latest/processing/color-calibration/manual.html) 对参考区域与线性数据的说明，以及 [LifePixel 改机说明](https://www.lifepixel.com/infrared-faq)；未移植第三方代码。这里的工作流不同于 Siril 对未拉伸线性天文图像的测光／背景校准，不应混称。

## 处理与限制

右侧“自动推荐参考点”在后台分析最长边 1000 像素的缩略图，筛选未过曝、亮度足够、局部纹理与颜色变化较小的区域，最多标出 5 个分散的编号。点击编号仅临时预览，点击“应用此参考点”才写入设置；取消恢复原设置。预览待确认时禁止保存设置和导出，防止预览与结果不一致。实际增益仍从原始像素取样，切换照片清除候选。

这些点不是已确认的中性灰，也不是星表测光校色：算法不能识别银河具体部位，无法区分均匀地景、尘埃、光污染与真实天空背景。请人工排除这些区域，找不到可信参考时使用同设备、同滤镜的灰卡预设。不会因改机红色较多自动认定为偏色。参考 [Siril 背景处理说明](https://siril.readthedocs.io/en/latest/processing/background.html) 对真实星云与背景的区分原则；推荐算法独立实现，未移植第三方代码。

- 使用线性 sRGB 的逐通道增益，之后编码回 sRGB；查找表保证零调整的所有 16 位输入值精确不变。显式嵌入其他 ICC 色彩空间的图片要求先转换至 sRGB；无 ICC 的图像按 sRGB 处理。当前不支持浮点／线性 TIFF、CMYK、透明通道图像。
- RAW 先使用选定的相机／固定日光基准、关闭自动提亮，解码至 16 位线性 sRGB，再编码进入上述处理流程。后续调整是解码后的 RGB 校正，不是 RAW 传感器级白平衡；已经裁切的高光无法恢复。
- 过强的增益可能裁切通道，预览下方显示可见区域的通道触顶比例；它不是全图过曝统计。星点原有颜色不会被自动识别为偏色并逐颗中和。
- 原始像素只读。预览采用多分辨率缓存和可替换后台任务，只处理可见区域；缩小视图存在重采样差异，1:1 用于检查原始细节。调节参数或切换对比不重置视口。
- 导出重新读取原片，按 128 行分块处理，内存映射写入 16 位 TIFF，嵌入 sRGB ICC。取消时保留标记为 cancelled 的记录，未完成文件不会命名为 result.tif。
- 解码、导出在后台执行。关闭工作区发出取消，文件解码／写入等不可中断阶段完成后停止。

## 来源与许可

计算及工作区代码为本项目自行实现，没有复制第三方代码或引入新依赖。sRGB 转换公式参考 [ICC sRGB 规格](https://registry.color.org/rgb-registry/files/sRGB.pdf)，RAW 调用参数依据 [rawpy 官方 API](https://letmaik.github.io/rawpy/api/rawpy.Params.html)。现有依赖继续适用各自许可证。

测试使用合成 16 位素材验证像素、取样、视口和实际导出；没有真实相机 RAW 样本时，不把 RAW 格式支持列表视为逐机型验证承诺。macOS 本轮未作实机验证。

验证范围：201 项单元测试；工具箱交互覆盖推荐参考点、预览取消与确认、缩放后的编号位置、滑块、原图对比、中性点取样、设备预设保存／恢复、跨照片沿用、批量一致性、失败计数及应用内日志、原片哈希和 16 位导出，另包含最小窗口设置可达性。原有 61 项合成交互回归继续执行。RAW 固定基准验证调用参数，没有真实改机 RAW 样本的效果验证。
