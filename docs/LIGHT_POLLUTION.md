# 光污染渐变校正

入口：**色彩工具 → 光污染渐变校正**。所有修改和导出操作在右侧，底部仅显示状态和进度。

1. 打开 RAW 或 sRGB TIFF／PNG／JPG。
2. 默认光污染来自底部；也可选择顶部、左侧或右侧。渐变起点按“远离光源端 → 靠近光源端”的方向计算，0% 表示整个画面。
3. 勾选“保护地景／星云”，在画面中拖动矩形。支持多个框，框内不参与估计，也不修改像素；边缘外侧平滑过渡。按需先保护地景、银河、星云、城市灯光等真实结构。
4. 点击“估计光污染背景”，然后调整去除强度。默认 60%，0% 为不校正；修改方向、起点、曲线或保护区后需重新估计。
5. 对比原图，确认后导出 16 位 TIFF。输出采用独立时间戳文件夹，附带 `light_pollution.json` 记录模型、参数、保护框和任务状态。原片只读，取消后不把未完成文件标记为正式结果。

## 方法与边界

缩略图上分格提取低分位背景样本，在线性 sRGB 中对一个方向的平滑渐变进行稳健回归，分别估计 RGB 的附加背景。校正减去估计的附加分量，而不是按固定比例压暗整片地景。不会强制背景中性化；对负斜率不作减法，暗像素限制扣除量以避免直接剪成黑色。

它不能可靠识别天空、地景或星云，也不能保证自动分离均匀星云和光污染。保护框是用户指定区域，不是 AI 分割。主要适合单方向渐变；局部灯光、复杂横向色块、眩光和过曝需要其他处理。全光谱改机混入的红外不能靠此功能恢复为真实可见光颜色。

预览仅处理可见区域，滑动强度不重新分析整张图。导出重新读取原片、按 128 行处理完整 16 位像素。RAW 沿用相机白平衡解码；色彩空间限制与白平衡模块相同。缩小预览存在重采样差异，1:1 更适合检查细节。

加性背景与真实天体信号区分原则参考 [Siril 背景提取说明](https://siril.readthedocs.io/en/latest/processing/background.html)。本功能自行实现，没有复制外部代码或引入依赖。当前验证使用合成渐变、星点和保护区域，不代表已完成真实星野、各类改机或 macOS 实机效果验证。
