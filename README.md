# 流星影像工坊（Meteor Studio）

跨平台 GUI，包含两个互不干扰的工作区：

- **流星合成**：按不含扩展名的主文件名逐对匹配流星/对齐 TIFF 和干净底图（JPG、PNG 或 TIFF），把流星自然融合到底图。
- **视频动态**：从视频中分离流星亮度层，在背景正常播放的同时，单独控制流星的慢放、停留、淡出、亮度和时间曲线。

源素材始终只读，所有结果只写入新的项目或输出文件。

详细文档：

- [完整使用指南](docs/USER_GUIDE.md)
- [macOS APP、DMG、签名与公证](docs/MACOS_BUILD.md)

## 下载程序

无需安装 Python，可直接从 [GitHub Releases](https://github.com/WallfacerMajor/MeteorStudio/releases/latest) 下载：

- `MeteorStudio-Windows-x64.zip`：Windows 64 位。
- `MeteorStudio-0.2.1-arm64.dmg`：Apple Silicon Mac（M1/M2/M3/M4 等）。
- `MeteorStudio-0.2.1-x86_64.dmg`：Intel Mac。

Release 中的三个安装包由 GitHub Actions 在对应操作系统上从当前源码自动构建。macOS 安装包尚未使用 Apple Developer ID 公证，首次运行方法见 macOS 构建文档。

## 使用

界面按 `1 流星合成功能 → 2 星空对齐 → 3 蒙版与候选 → 4 融合与底图 → 5 所选流星 → 导出` 分组。匹配成功后流星合成设置自动收起，窗口顶部可随时重新展开；切换原图/底图/融合视图时会自动打开对应参数页，所有原有按钮和快捷键仍保留。

窗口顶部的“流星批量筛选”用于从连续相机 RAW（Sony ARW、Nikon NEF/NRW、Canon CR2/CR3/CRW）及 TIFF/JPG/PNG 照片中找出疑似含流星的原图，不要求预先提供干净底图。RAW 只会在内存中解码用于分析和预览，源文件保持不变。程序按 EXIF 时间或文件名排序，用当前帧前后最多 3 张照片生成临时参考；相邻星点位移超过约 1.2px 时才执行缓存内配准。分析会先按每张照片的星点密度、固定结构和纹理动态估计星空区域，再只在星空内寻找轨迹，不使用固定高度切掉地景。候选会结合内置 AI、断续灯迹和跨帧重复方向评分。用户只需调整“筛选灵敏度”：向“候选更多”移动可以尽量避免漏掉弱流星，向“候选更少”移动可以减少误选，再人工保留或排除。导出只会把确认的原文件复制到新的时间戳文件夹，并保存 `screening_report.json`，绝不移动或改写源文件。

筛选会根据 CPU 数量自动安排并行任务：RAW/JPG 解码与逐帧检测使用独立线程池，避免 OpenCV 在每一帧内部重复抢占全部核心。静止机位先执行快速位移判断，仅在确实需要时运行完整星点特征配准；全图统计值也会复用。无需手动设置线程数，内存缓存保持有界。

筛选列表使用颜色区分自动保留、人工保留、自动排除、人工排除和疑似飞机/卫星。右侧预览随窗口尺寸重排，支持滚轮缩放、拖动、适应窗口和 1:1；按住 `H` 可临时查看完全没有标记的原图。候选标记改为流星两侧的细导轨，不再覆盖流星核心和弱尾迹。

需要检查星点、弱尾迹和候选边缘时，勾选“原图精细预览”。程序会按需读取当前照片的原始像素尺寸；RAW 使用完整尺寸 AHD 解码，TIFF/JPG 使用原始分辨率。高清缓存最多保留最近五张，不会预先载入整批素材。切换照片时可先显示快速预览，原图加载完成后自动替换；点击“1:1”可按一个原图像素对应一个屏幕像素检查。

“保留这张照片”只决定是否导出照片，不会给 AI 产生正样本。必须在预览中点击具体候选，再选择“这条是流星 / 这条不是流星”，才会形成候选级训练反馈。自动检测漏掉流星时，可点击“手动标记漏检流星”，再依次点击起点和终点。筛选与流星合成使用同一个候选特征、排序模型和个性化模型文件；候选级反馈会在下一次执行 AI 学习时一并使用。

候选判断会联动照片状态：确认任意一条是流星或手动补标流星时，照片变为“候选保留”；当一张照片中的所有候选都被明确标为不是流星，并且没有真实流星标记时，照片变为“候选排除”。撤销任意候选判断会恢复分数自动判断；照片级保留/排除按钮仍可在之后手动覆盖。

筛选工作区独立自动保存分析结果、照片级保留/排除、候选级确认、手动补标、灵敏度、路径和预览选项。修改后约 0.9 秒写入应用数据目录，关闭窗口时再立即保存一次；下次进入筛选工作区自动恢复。自动保存只记录路径、坐标、分数和AI特征，不复制原图，也不保存高清像素缓存。

顶部入口采用单工作区导航：进入视频动态或 Siril＋PTGui 对齐时，流星合成界面会自动隐藏；点击“返回流星合成工作区”或关闭当前工作区即可返回，不会同时显示两个完整界面。

1. 安装 Python 3.11 或更高版本。
2. 安装依赖：`python -m pip install -r requirements.txt`。
3. Windows 双击 `run_windows.bat`。macOS 首次先执行 `chmod +x run_macos.command`，再右键该文件选择“打开”。
4. 先选择输出方式。“拼合到同一张底图”只能选择一张底图并输出一张累计总图；“分别输出”可选择一张/多张底图文件或底图文件夹，并按主文件名配对。例如 `DSC04924.tif` 匹配 `DSC04924.jpg`。
   更换底图后会立即重建同名配对、清除旧预览缓存并重新载入当前图片；导出前还会再次校验，避免继续使用上一次的底图。
5. 点击“只读扫描”，然后点击“自动检测全部”。程序先生成高召回线状候选，再由内置本地 AI 根据亮度峰值、连续性、头尾渐变、背景差异、方向等 34 项特征重新判断；最后向头尾延伸并扩大、羽化蒙版，以覆盖亮部光晕和渐隐尾迹。
6. 选择 TIFF 后可在“流星素材图 / 干净底图 / 融合后预览”之间切换。红色蒙版和候选只显示在 `1 流星素材图`；`2 干净底图` 始终显示未经覆盖的只读底图；`3/4` 显示最终合成和来源标注。编辑视图中按住 `H` 可临时隐藏红色蒙版，松开恢复显示。
   主画布支持鼠标滚轮缩放、`+/-` 缩放、中键拖动或按住空格加左键拖动平移；`Ctrl/Command+0` 适合窗口，`Ctrl/Command+1` 查看 100% 原图像素。缩放和平移只读取并缓存可见视口，不会触发整图融合重算。
7. 自由绘制时直接拖动。画直线时先单击起点，再按住 Shift 单击终点；可以继续 Shift+单击画折线段。
8. 画布使用动态工具光标：实线圆圈显示画笔/橡皮擦硬宽度，虚线外圈显示羽化范围，橡皮擦中心带蓝色橡皮图标。调整滑块时光标实时改变。画笔和橡皮擦各自保存独立宽度。切换到“橡皮擦”后按下并拖动，红色蒙版会实时消失；Shift+单击也能直线擦除，“撤销上一笔”可恢复整次擦除。
   所有画笔和橡皮擦严格按绘制顺序计算：画笔→橡皮擦→再次补画时，最后补画的区域会恢复，不会被早先的橡皮擦永久清除；连续多笔画笔也始终累加。
   画笔采用普通绘图软件的直接交互：按下并拖动就是连续加笔，前台红色笔迹跟随鼠标，松开后一次性并入现有蒙版；按住 Shift 则从上一笔终点直连到当前点。新笔画永远不会隐藏或替换前面的笔画，按 `Esc` 只取消当前尚未提交的一笔。
   绘制期间软件会捕获鼠标，并在整个窗口范围接收松开事件；即使系统在画面刷新时漏掉一次松开，下一次按下也会先自动提交上一笔，绝不会用第二笔替换第一笔。
   相邻、交叉和部分重叠的画笔严格做并集，后一笔画笔不能减少前一笔的任何蒙版像素。候选阈值刷新也不会再重排“画笔→橡皮擦→补画”的历史顺序；若 Alt/Option 松开事件被系统菜单吞掉，下一次未按 Alt 的点击会自动恢复画笔/橡皮擦原状态。
   若要删除一整条画笔/自动检测蒙版，可在红色蒙版附近右键并选择“删除整条蒙版”，也可用 `Shift+右键` 直接删除。普通左键始终只属于画笔/橡皮擦，不会误删邻近蒙版。删除整条同样支持撤销和重做。
9. “保持流星亮部”默认开启，避免蒙版羽化、局部曝光匹配以及旋转/拉伸插值让流星核心变暗。“全局亮度”默认 `100%`，只增减流星相对底图的正向亮度，不提亮周围天空；范围为 `50%–250%`。当前图片可勾选“单独设置”，否则跟随全局。“全局背景净化”会从蒙版边缘估计并移除原图天空与底图之间的平滑色偏/亮度差，减少矩形色块和光圈接缝。
10. 在 `3 最终融合` 或 `4 来源标注` 中单击一颗流星，可启用“单颗独立设置”。亮度、背景净化、饱和度、保持亮部、局部曝光/颜色匹配、混合方式和羽化都只作用于这一颗流星；取消勾选后重新跟随当前图片与全局参数。设置会随项目自动保存并用于预览和导出。
    移动、旋转或拉伸时，流星像素和蒙版会使用同一变换实时预览；不是只移动选框。松开鼠标后再生成精确的最终融合与来源标注。
    发生几何变换的流星会显示“已人工变换”。在 `1 流星素材图` 中仍保留原位置的真实流星，同时显示变换后的流星副本；青色虚线表示原位置，橙色实线表示变换后位置。所选流星工具栏及右键菜单均提供“一键恢复原位”，只恢复位置、旋转和长宽比例，不改变蒙版、透明度或独立融合参数。
    拼合模式下，移动、微调、恢复以及单颗融合参数变化会先增量更新当前流星层，其他天空区域继续使用现有缓存；连续滑块变化会合并，停止操作后才在后台执行一次精确校验。画布图片对象会复用，不再因小改动先清空整张画面。正式导出仍从源文件完整计算。
    合成器只允许蒙版中的主流星连续亮光进入底图，不会把宽羽化区域内的原图天空、普通星点、地景或投影接缝一起粘贴。总融合预览采用单任务合并刷新，拖动参数时不会并发堆积重复渲染。
11. 自动检测漏掉流星时，先加载该图并点击“本地模型分析当前单张”。程序会为最多 60 条候选给出 1–100 的流星评分；拖动候选评分阈值，达到阈值的候选会即时加入蒙版。阈值越低，加入越多。按住 `H` 可查看分数。鼠标靠近任意候选轨迹时会弹出绿色“＋选中”按钮，点击即可绕过当前阈值，直接加入并锁定该候选。
12. 确认某条流星后，在该蒙版附近右键选择“锁定这条蒙版”。锁定蒙版不会因调整阈值、再次分析、自动检测全部或“清除此图蒙版”而消失；最终合成画布中的主动变换或删除仍然有效。候选、分数、阈值和锁定状态都会随项目保存。
13. 拼合模式把全部已选流星累计到共享底图后输出一张无标记总图，并额外输出一张带来源框线和 TIFF 主文件名的“来源标注”诊断 JPG；分别输出模式为每组配对生成独立成品及对应的“来源标注”图。在新建的时间戳运行目录中输出 `final_jpg`、蒙版和处理报告，可以勾选同时导出16位 TIFF。
    每颗流星独立记录“自动对齐素材”或“原始素材”。同一张照片里的对齐流星可以保持不变，同时从原始图提取画外流星再移动到画布中。原始素材流星会在来源标注图中使用红色警示框、黄色外框和顶部警告条，并标记 `ORIGINAL / UNALIGNED`；最终无标记成品不受影响。
    人工移动、旋转或拉伸过的流星使用橙色框和 `TRANSFORMED` 标签，并以青色虚线框与箭头保留其原始位置参照；处理报告同时记录每颗流星的完整变换参数。

## 视频动态工作区

在主窗口右上角点击“打开视频动态工作区”。视频模块目前支持：

- **仅视频**：用流星帧前后的非流星帧估算同一时刻的干净背景，不需要 TIFF、JPG 或外部蒙版。
- **流星视频＋干净参考视频**：两段视频必须尺寸、帧率和帧数一致，按同帧差分提取流星，暗弱尾迹通常更稳定。
- **图片序列高质量链路**：先在流星合成工作区生成准确的逐帧素材，再编码为流星视频或干净参考视频。

推荐流程：

1. 选择素材方案、流星视频和独立输出目录；需要时再选择干净参考视频。
2. 设置“忽略底部”比例，排除地平线和地景，然后执行自动分析。
3. 调整分数阈值。程序只负责提出候选，最终由用户决定：`Enter` 保留、`Delete` 排除、空格锁定。
4. 选中候选后用画笔补画完整流星和尾迹，用独立宽度的橡皮擦修整；右键可删除或锁定整条蒙版。完全漏检时可手工输入帧编号。
5. “周边净化”会自动模拟 PS 的“变亮＋色阶黑场＋软边蒙版”：先校正局部天空色偏，再按亮度压掉微弱彩色残差，最后柔化信号边缘。它不会用单个 RGB 通道的轻微偏亮来判断流星，因此可减少宽蒙版内的淡色块；每颗流星仍可单独调整。
6. 在总融合预览中删除一颗流星时，只重建它原来覆盖的局部并立即更新来源标注，不启动全局合成；若下面还有其他流星，只在该局部按原顺序重新叠加相交流星，画面其余部分完全沿用缓存。
7. 新增画笔、橡皮擦或点击候选生成蒙版时，也只重建新增蒙版覆盖的局部及相交流星；切换到总融合预览不会因此重新合成整张画面。
8. 拖动、旋转或拉伸后撤销只恢复该流星的上一个几何状态；即使对象顺序发生变化也会按状态定位原对象。没有有效撤销记录时保持蒙版不变，不再猜测并删除最后一条蒙版。
9. “底图曝光”支持 -2.0 EV 到 +2.0 EV 实时调整，只改变干净底图，流星信号及每颗流星的亮度设置保持独立；预览、来源标注、JPG 和 16 位 TIFF 导出一致。
10. 默认背景净化加强暗部黑场抑制，在保护流星核心和尾迹的同时，进一步消除暗天空中仔细观察才能看到的低亮度色块边界。
11. 主画布从载入开始就保留原图完整像素，不再固定缩到 1800px。素材图与底图可直接放大到 100% 检查；最终融合和来源标注在后台自动使用原始尺寸、16 位及与导出相同的合成顺序更新，无需再点击“生成精确预览”。更新期间先显示逐张累积结果，完成后当前画布自动替换为原始像素结果。
    程序按可用内存设置字节上限，缓存当前素材的 8 位显示层、16 位计算层、底图、相邻图片和已缩放视口；相邻图片在后台并行预取。画笔红色覆盖、移动和删除只更新受影响矩形，不会为一个小改动创建整幅 float32 中间图。
12. “自动优化每颗流星”会按原尺寸分别读取蒙版外圈，估算局部亮度、RGB 色偏和噪声，拟合低频背景并生成该颗流星独立的黑场、背景净化、亮度补偿和有效羽化。保守/标准/强力三档会结合实际信噪比自适应，不是把一套固定曲线复制给所有流星。
13. 可自动优化当前流星或全部流星；单颗设置栏显示实际生成的参数。“恢复自动值”清除亮度/净化的手动覆盖并重新使用分析值，“恢复原始融合”只关闭该颗流星的自动处理。手绘蒙版本身不会被改写。
7. 移动、旋转、拉伸、一键恢复、变换撤销/重做和单颗融合参数调整都会精确重建该流星旧位置与新位置的联合区域；不再安排延迟全图校验。只有底图、输出模式或全局融合参数变化等真正影响全部流星的操作才重建总预览。
8. 画笔和橡皮擦拖动时只绘制轻量前景轨迹，并按屏幕距离过滤重复采样；松开鼠标后才提交局部蒙版与融合，拖动期间不会重建整张羽化蒙版。
5. 如果一颗流星跨越连续多帧，用 Ctrl/Shift 多选后“合并所选连续帧”，然后在事件内逐帧修蒙版；也可再拆分回单帧事件。
6. 设置全局效果；个别流星可点击“当前流星单独参数”覆盖全局值。
7. 在“原视频帧 / 提取的流星层 / 融合后效果”之间检查，再导出。

可独立调节的参数：

- 效果模式：延长并淡出、仅流星慢放、慢放并淡出。
- 流星局部速度：先清除流星的原时序显示，再对单帧或多帧流星层做速度曲线重映射；背景始终正常播放。
- 清晰停留、淡出时间、流星亮度、蒙版宽度和羽化。
- 时间曲线：匀速、渐慢、渐快、S曲线或自定义起始/中段/结束速度。
- 背景播放速度：与流星局部速度完全分开；背景设为 75% 时，流星的停留和淡出时间不会被同步拉长。
- 导出质量默认“匹配源视频”，读取源码率后以接近的高码率输出；也可选 CRF 12 或 CRF 18。
- 高码率输出使用 H.264 Main Profile、无 B 帧、单参考帧和每秒关键帧，避免部分硬件播放器出现全屏色块。
- 可选择保留音频；背景变速时音频会同步变速以匹配新时长。

视频候选、人工判断、锁定状态、逐帧画笔/橡皮擦蒙版、多帧分组、导出质量和每颗流星的单独参数都会保存到 v3 视频项目 JSON，并独立自动保存。v1 项目中的直线轨迹会自动转换为画笔蒙版。

## 自动保存与恢复

- 修改蒙版、锁定、候选阈值、输入输出路径或合成参数后，程序会等待约 0.8 秒自动保存，窗口底部会显示保存时间。
- 下次启动会自动恢复上次会话，包括所有蒙版、候选、锁定和每张图的阈值。
- 自动保存采用临时文件写完后再原子替换，避免程序中断留下半份项目文件。
- 图片项目沿用旧位置 `%APPDATA%\MeteorComposer\autosave.json`，保证升级后仍能恢复；视频项目保存于 `%APPDATA%\MeteorStudio\video_autosave.json`。macOS 使用对应的 `~/Library/Application Support/...` 目录。自动保存不会写入输入素材文件夹。
- “保存项目”和“载入项目”仍可用于制作具名备份或在不同电脑之间迁移。

## 内置 AI 模型

- `meteor_ranker.json` 是约 39 KB 的梯度提升候选分类模型，在本机 CPU 离线推理；照片不会上传，也不需要 PyTorch或连接网络。只有用户主动选择“导出并自动学习”时才会使用随程序安装的 scikit-learn 训练组件。
- 模型由“明安图合成.json”的最终人工蒙版监督训练：603 条候选中有 98 条正候选、505 条硬负候选。验证严格按整张图片分组，避免同一图片同时进入训练和验证。
- 五折留图验证中，旧公式的 AUC/平均精确率为 0.664/0.290，新模型为 0.913/0.761；逐图取最高分候选的正确率从 27/64（42.2%）提高到 55/64（85.9%）。
- AI 负责候选判断和排序，传统图像算法仍负责候选生成和蒙版形状。因此候选阶段完全漏掉的流星仍需手工补充或后续扩展高召回检测器。

## 导出时自动学习

- 点击“导出合成结果”后会出现三项选择：“是”代表导出后自动学习，“否”代表仅导出，“取消”停止操作。
- 自动学习把最终保留蒙版覆盖到的候选作为正样本，未覆盖候选作为硬负样本；基础训练数据与本次反馈合并后，仍按整张图片进行五折验证。
- 新模型的平均精确率或逐图最高分正确率明显退步时不会替换原模型。通过验证后，新模型保存到系统应用数据目录并立即启用，程序安装目录和输入素材保持不变。
- 每次成功替换前都会在 `MeteorComposer/models/backups` 中备份旧模型。学习失败不会回滚、删除或改变已经导出的照片。
- 通过验证的训练会同时累计保存模型和去重后的训练数据集；维护者发布新版本前可运行 `python promote_personal_model.py`，把本机验证模型及累计数据集晋升为安装包内置资源。

## Siril＋PTGui 星空对齐

主窗口点击“`Siril＋PTGui星空对齐…`”进入完整工作流：

1. 选择一张对齐参考图、完整流星原图文件夹和独立输出文件夹。这里的图片只负责定义目标投影与画布，不等同于合成工作区里的“干净底图”。
2. Siril CLI 在逐张只读代理图上检测星点；MeteorStudio自动转换Siril坐标、判断可信星区并生成稀疏的星点有效区蒙版，只允许可信星点附近特征进入稳健控制点筛选。单应性预筛至少需要4组非共线控制点；4–5组会继续导出但标为“需复查”，6组以上且误差合格才作为正常结果。
3. 软件从对齐参考图和每张流星图各自的EXIF读取焦距（包括Lightroom TIFF的ExifTag子目录），在PTGui中建立独立镜头组；变焦或混用不同焦段时不再强制共享固定焦距。随后为每张流星图建立独立的“对齐参考图＋完整流星图”PTGui工程，单张失败不会影响其他图片。
4. PTGui只负责优化星空位置，并原生导出与对齐参考图相同画布的16位分层TIFF。流星蒙版仍在MeteorStudio内处理，不会修改源素材。
5. 导出层自动回载到主工作区，随后才进行流星候选判断、人工蒙版和合成。

界面的焦距和传感器对角线现在只用于EXIF缺失时兜底；结果列表会逐张显示实际焦距来源和自动星点有效区覆盖率。这个覆盖率代表用于匹配的星点邻域，并非整片天空的面积。星空区域无需手动设置固定比例。低置信度图片仍会尽力生成基础对齐并标为“需复查”；完全无法求解时保留原始状态。主工作区可以切换当前查看/绘制源，每颗流星还可独立决定使用自动对齐素材或原始素材。

“对齐实验室”默认关闭，不影响正式流程。启用后可以选择透视、墨卡托、等距柱状或立体投影，并把公共天空画布扩展到参考视场的135%或170%。输入镜头仍按EXIF保持原始透视模型；对齐参考图与全部流星层统一重投影，因而能直接返回合成工作区比较流星直线、弧线和辐射感。实验结果写入独立的 `MeteorStudio_PTGui_Lab_*` 任务目录，不覆盖正式对齐。

对齐任务只在新建的 `MeteorStudio_PTGui` 任务目录中写入缓存、PTGui工程、日志、对齐图层和最终合成。原始对齐参考图和流星照片保持只读。

## 每颗流星的自由变换与融合

- 在一条正向流星蒙版附近右键，选择“进入预览直接移动／旋转／拉伸”。软件会切到当前图融合预览并直接显示与总融合预览相同的变换框和手柄，不再弹出参数窗口。
- 可独立设置水平/垂直移动、旋转、沿轨迹拉伸、横向宽度和不透明度；“一键恢复原位”仅清除几何变换，保留蒙版、不透明度与融合设置。
- 变换参数保存在项目JSON中，不会反复重采样原图。
- 合成方式包括“自然融合”（默认）、“亮度残差”和“普通粘贴”。
- 无法自动对齐的图片会保留在对齐工作区，用户可以丢弃或之后人工处理。

## 快捷键

- `B` / `E`：画笔 / 橡皮擦。
- 按住 `Alt`（macOS 为 `Option`）：临时在画笔与橡皮擦之间切换，松开后恢复原工具。
- `[` / `]`：减小 / 增大当前工具宽度；`Shift+[` / `Shift+]` 调整羽化。
- `Ctrl/Command+Z`：撤销；`Ctrl/Command+Shift+Z` 或 `Ctrl/Command+Y`：重做。
- 蒙版附近右键：菜单删除整条；`Shift+右键`：直接删除整条。普通左键始终只用于画笔/橡皮擦。
- `1` / `2` / `3` / `4`：原图、干净底图、无标记最终融合、来源标注预览；第 3/4 视图使用同一合成缓存并可随时切换。
- 第 3/4 视图也是可编辑的最终合成画布：单击流星后可直接拖动；端点手柄调整长度，侧边手柄调整宽度，四角等比例缩放，圆形手柄旋转。`Delete/Backspace` 删除，方向键微移，`Shift+方向键` 每次移动 10 px，右键可重置或输入精确参数。修改会同时更新无标记成片和来源标注预览。
- 蒙版锁定用于防止 AI 阈值变化、重新检测或“清除此图”误删；最终合成画布中的主动移动、变换和删除仍然有效。红色蒙版默认显示，按住 `H` 临时隐藏，松开恢复。
- `←` / `→`：上一张 / 下一张；`Esc` 取消当前尚未完成的一笔。
- `Ctrl/Command+S`：保存项目；`Ctrl/Command+O`：载入项目；`Ctrl/Command+Enter`：导出。
- `F1`：在程序中查看完整快捷键表。

## 安全边界

- 不修改、移动、重命名或删除 TIFF/JPG 输入文件。
- 输出目录必须与 TIFF、JPG 两个输入文件夹分开，不能互相包含。
- TIFF 先写入 `.writing.tif` 并校验，再原子改名为正式文件。
- 如果最终文件已经存在，程序自动添加 `_v2`、`_v3`，不会覆盖已有结果。

## 跨平台打包

Python 源码本身跨平台。原生应用必须在目标系统上打包：

```bash
python -m pip install pyinstaller
# Windows
pyinstaller --noconfirm --windowed --name MeteorStudio --hidden-import meteor_learning --hidden-import video_meteor --hidden-import alignment_workspace --hidden-import ptgui_pipeline --add-data "meteor_ranker.json;." --add-data "candidate_dataset.npz;." meteor_composer.py
# macOS
pyinstaller --noconfirm --windowed --name MeteorStudio --hidden-import meteor_learning --hidden-import video_meteor --hidden-import alignment_workspace --hidden-import ptgui_pipeline --add-data "meteor_ranker.json:." --add-data "candidate_dataset.npz:." meteor_composer.py
```

在 Windows 执行会生成 `MeteorStudio.exe`，在 macOS 执行会生成 `MeteorStudio.app`；PyInstaller 不能在 Windows 上直接生成 macOS 应用。

也可以直接使用随附的 `build_windows.bat` 或 `build_macos.command`。在 Mac 上执行 `./build_macos_dmg.command 0.1.0` 可一次生成 APP 和 DMG，详见 [macOS 构建文档](docs/MACOS_BUILD.md)。
